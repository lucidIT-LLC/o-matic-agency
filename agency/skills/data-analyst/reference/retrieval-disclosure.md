# Degraded retrieval disclosure

The skill carries the trigger, the literal state line, and the three required fields. This file is the full template.

## Contents

- When it fires
- Template
- What does not count

## When it fires

Any deliverable — briefing, status, report, or an answer meant to be pasted — built wholly or partly on keyword-only retrieval instead of semantic search. The search tool was unavailable, skipped, rate-limited, or withheld because the operator said to. It fires even when the keyword search finds the right answer. Success does not repair the method.

## Template

Open the deliverable with this, filled in, and nothing before it:

> Retrieval state: DEGRADED. This is a keyword-only sweep, not semantic retrieval — [reason: unavailable, rate-limited, or withheld at the operator's instruction].

The three required fields are:

1. The literal state line, including the word DEGRADED.
2. The contrast: keyword, not semantic.
3. The reason.

Findings follow. A caveat after the findings is a caveat a skimming reader never reaches.

## What does not count

- "ILIKE, no embeddings used."
- "Keyword match."
- A tool-log appendix the operator will not paste.
- A paraphrase that never uses the word DEGRADED.

Name the mechanism in the findings if it helps. It does not replace the opening line.
