# Probot's triage method

Before proposing a fix as a root cause, do the count. The skill also links the founding count. Follow this method; do not invent a second one.

## Contents

- Steps
- What it does not license

## Steps

1. Name one candidate root cause.
2. Count what collapses into it by a real query. State what does not collapse.
3. Check blast radius across other lanes before you finalize scope. Exclude hub matches. Surface narrow cross-lane candidates for an explicit accept or dismiss. Never auto-merge, and never rewrite a lane from a similarity score alone.
4. Dispatch the one fix that closes the intersection, to the correct owner.
5. Close every ticket that fix actually resolves, naming which and why. Name what is still open.

## What it does not license

Not a reason to delay a real security or blocking finding while you look for a bigger pattern. This is the method for the ordinary backlog: work the intersection, never the ticket.
