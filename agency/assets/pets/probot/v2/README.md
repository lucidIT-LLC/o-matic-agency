# Probot pet art

This is the original exported **v2** animated pet sprite sheet for Probot. The versioned transparent PNG can be downloaded directly as [probot-pet-v2.png](https://raw.githubusercontent.com/lucidIT-LLC/o-matic-agency/main/agency/assets/pets/probot/v2/probot-pet-v2.png). Metadata is in [`metadata.json`](metadata.json).

## Install in Codex desktop

After this change is merged, open the [Install Probot pet](codex://pets/install?name=Probot&imageUrl=https%3A%2F%2Fraw.githubusercontent.com%2FlucidIT-LLC%2Fo-matic-agency%2Fmain%2Fagency%2Fassets%2Fpets%2Fprobot%2Fv2%2Fprobot-pet-v2.png&description=A+loyal+o-MATIC+factory+companion+that+shows+Codex+activity+and+honest+factory+context.&spriteVersionNumber=2) link. It opens Codex's pet install flow and passes the public sprite URL with `spriteVersionNumber=2`. The plugin marketplace install and pet install are separate steps; installing this plugin does not select or activate the pet.

The pet is artwork only. It does not change Probot's skill, identity, or behavior, and it does not provide live factory telemetry. Custom pets are stored locally and do not automatically sync to ChatGPT web. The web upload flow currently documents a different 1536 × 1872 sheet size, so this v2 atlas is intended for Codex desktop and compatible Codex CLI use.

See [Codex pet install links](https://learn.chatgpt.com/docs/reference/commands#pets) and [ChatGPT Pets](https://learn.chatgpt.com/docs/pets) for current host support.
