# System 5.6 Role Canonicalization Register

## Standard applied

- **Stuff You Should Know:** durable factory behavior is database-owned and
  portable across hosts; one canonical role contract is delivered through thin
  host adapters.
- **Stuff You Should Forget:** remove obsolete bootstrap paths, retired runtime
  instructions, duplicate authority, local credential/config assumptions, and
  unsupported capability claims.

## Remediation rule

An active role file may contain only identity, its specialty, current operating
boundary, current tool discipline, required evidence, and handoff behavior.
Historical implementation detail belongs in an explicitly historical record;
shared System 5.6 doctrine belongs in the canonical contract and governed
retrieval, never duplicated across every role.
