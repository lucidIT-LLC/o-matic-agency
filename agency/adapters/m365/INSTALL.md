# Microsoft 365 Copilot — Probot, Fred, and Data

GENERATED by scripts/build-host-adapters.mjs from agent-pack.json (gold record) and each role's SKILL.md. Do not hand-edit.

One app per role. Each package is a declarative agent (schema v1.9) plus a Teams app manifest (1.30). Tool-using roles also ship a plugin (schema v2.4) that pins at most 8 read-only o-MATIC tools. `factory_query`, `startup`, and every write tool stay out of the pin list.

Nothing in this directory is deployed. SSO is not live, and the read-only database login is not live. Do not sideload, upload to an org catalog, or attach these zips to a release from this change.

## Build

```
node scripts/build-m365-packages.mjs .
node scripts/verify-m365.mjs .
node scripts/verify-m365.mjs . --dist
```

The zip lands in `dist/m365/`, which is gitignored. The build fills `${{TEAMS_APP_ID}}` and `${{OMATIC_MCP_URL}}` from `adapters/m365/<role>/env/.env.sample`. Those values are TODO placeholders. They are not a tenant id and not a private host.

## What each package contains

| Role | Path | Tools |
|---|---|---|
| Data | `adapters/m365/data/appPackage/` | connections_list, omatic_guide, search, db_health_snapshot, task_relationships, slate_entity_search |
| Fred | `adapters/m365/fred/appPackage/` | connections_list, omatic_guide, search, proposal_vault_list, proposal_vault_get, ocr_result_get |
| Probot | `adapters/m365/probot/appPackage/` | connections_list, omatic_guide, search, task_relationships, task_duplicate_check, slate_entity_search, slate_entity_verify, module_status |

The first factory these agents may read is o-MATIC Foundry, read-only. The connection name is read from `connections_list` at runtime. theNest and About Jimmy stay out.

Privacy and terms URLs are marked TODO until the public pages exist. Developer name and website are filled. Persona lines are the gold-record lines, unchanged.

## Icons

`color.png` is the 192×192 avatar. `outline.png` is the 32×32 white-on-transparent outline. Each manifest references both files.

## Host skills

Enable `m365-probot`, `m365-fred`, or `m365-data` beside the canonical skill (`probot-orchestrator`, `fred-storage`, `data-analyst`). The canonical skill is the lane. The host skill is the Copilot limit: read-only, pinned tools, drafts for anything the user would send.
