# Codex Adapter

Install the Agency plugin at `../../.codex-plugin` so Codex discovers the L1
skills in `../../skills/`. Load the compact resident core kernel contract before
or alongside any direct core-role or specialist invocation: Probot retains
orchestration, Fred retains custody awareness, and Data retains evidence and
retrieval boundaries. The canonical role contract and conformance suite remain
adjacent for release verification.

For L2, use a separate host agent harness only after it has an explicit workflow
record in `factory.agent_runtime_contracts`, a least-privilege allowlist, owner,
approval policy, rollback plan, and passing evaluation. A Codex skill alone is
L1 behavior, not an autonomous deployment.
